# marbiana.github.io

Персональный сайт-портфолио Марины Орловой: аналитика данных, e-commerce и ETL.

Сайт состоит из обычных HTML/CSS/JS-файлов и не требует сборки. После публикации репозитория через GitHub Pages он будет доступен по адресу `https://marbiana.github.io`.

## Локальный просмотр

Откройте `index.html` в браузере или запустите простой локальный сервер:

```powershell
python -m http.server 8000
```

После этого откройте `http://localhost:8000`.
